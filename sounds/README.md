# 自定义音效

这些文件由用户提供，仅用于本机点名工具的提示音。

| 文件 | 对应状态 | 说明 |
|---|---|---|
| `in0.mp3` ~ `in4.mp3` | 到了（连续递进） | 用户提供的“冰冰冰”5 段递进音：连续点“到”依次播 0→1→2→3→4，第 5 次及以后都用 `in4`，直到出现非“到”才重置 |
| `out.mp3` | 缺席（默认） | 用户提供的“暖冬家园”回城音 |
| `out-alt.mp3` | 缺席（备选） | 用户提供的 “siuuuuu” 音 |
| `leave.mp3` | 请假 | 用户提供的“哇哇哇哇”音 |

- 设置 → 音效风格里选择合成音时，不会播放这些文件；只有文件存在且加载成功才使用。
- 缺席音可在设置里切换 `暖冬回城` / `siuuuuu`。
- 若删除某个文件，该状态会自动回退到合成音效，不会报错。
